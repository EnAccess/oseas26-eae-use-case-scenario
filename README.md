# EAE for Use Case Scenario

An open-ended sandbox challenge to propose a completely unique, novel scenario or
use case for the
[Energy Access Explorer (EAE)](https://www.energyaccessexplorer.org).

## Abstract and goal

This is an open-ended sandbox challenge for students to push the boundaries of the
Energy Access Explorer. Teams are invited to think outside the box and propose a
completely unique, novel scenario or use case for EAE that goes beyond its
current traditional applications.

## Expected outcomes

- **The Scenario Pitch:** A compelling presentation defining the problem, the
  target audience, and why this new EAE application is vital.
- **Data Prototype / Workflow:** A demonstration of how EAE's existing data
  layers (or integrated external open data) can be combined to solve this new
  problem.
- **Impact Roadmap:** A brief strategy on how policymakers or NGOs could
  implement your unique EAE scenario in the real world.
